# FocusKPI Application Package

## Two-to-three-minute demo script

**Opening — 15 seconds**

> Hi, I’m Mohmed Abd-Elrahman Hafez, a recent Mechatronics Engineering graduate focused on Python, machine learning, APIs, and AI automation. I built Customer Events Workspace to demonstrate a practical customer-scoped AI workflow.

**Customer and event flow — 35 seconds**

> On the Customers page, I can create and search customer records. Opening a customer shows a newest-first event timeline. Each event has an event type, description, optional JSON metadata, and timestamp. The operator can add, edit, or delete an event, and delete a customer with a confirmation step.

**Grounded assistant flow — 40 seconds**

> In the Assistant page, I select one customer and ask a question such as, “What is the latest issue and the recommended next step?” The server retrieves only that customer’s events, then calls an LLM when available. If the service is unavailable, the UI switches to clearly labeled Mock mode. Every answer returns source event IDs so an operator can inspect the supporting evidence.

**Operations flow — 35 seconds**

> Data Ops provides a CSV preview workflow that validates customer rows before committing records. It also shows an audit stream. The application includes a documented webhook ingestion contract protected by a server-side secret, so automation tools can record customer events safely.

**Engineering close — 25 seconds**

> Technically, the project uses React, TypeScript, tRPC, Zod validation, Drizzle with MySQL, server-side AI integration, and Vitest. I designed it to show readable architecture, scoped AI retrieval, reliable error states, and practical integration thinking.
